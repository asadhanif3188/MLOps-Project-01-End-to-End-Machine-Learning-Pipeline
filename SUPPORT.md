# Support

Thanks for using this project! This document explains where to go for help.

Please review the [documentation](docs/README.md) first — many questions are
answered there, including the [architecture](docs/architecture.md),
[project structure](docs/project-structure.md), and
[GitHub workflow](docs/github-workflow.md).

## How to Ask Questions

For general questions and usage help:

- Use [GitHub Discussions](https://github.com/asadhanif3188/mlops-platform-on-eks/discussions)
  <!-- TODO: enable Discussions in repository settings, or replace this with the
  preferred channel. -->
- Search existing issues and discussions before opening a new one — your question
  may already be answered.

Please **do not** use the issue tracker for open-ended questions; reserve it for
actionable bug reports and feature requests.

## How to Report Bugs

- Open a new issue using the
  [Bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- Include steps to reproduce, expected vs. actual behavior, and your environment
  details.
- Do **not** include secrets or credentials in issue reports.

For security vulnerabilities, follow the [Security Policy](SECURITY.md) instead
of opening a public issue.

## How to Request Features

- Open a new issue using the
  [Feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- Describe the problem you're trying to solve, your proposed solution, and any
  alternatives considered.
- Where possible, relate the request to an item on the
  [roadmap](docs/roadmap.md).

## Documentation Issues

Found something unclear or incorrect in the docs? Open an issue using the
[Documentation template](.github/ISSUE_TEMPLATE/documentation.md).
